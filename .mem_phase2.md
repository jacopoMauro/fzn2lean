## CRITICAL lessons this session

- THE KEY CORRECTNESS INSIGHT: eqSlot's SatisfiedBy permits BOOL reads
  (x y, reads and x = y) while stdInterp int_eq is FALSE there. The
  CONVERSE needs int-valued-reads premises (p, a[i]! = .int p), which
  the final assembly must derive from well-formedness typing. The
  a->store direction is where TYPING enters.
- Nested `rcases h : e with | err => ... | ok opt =>` DOES NOT PARSE.
  Use the 3-arm `match hs : declSlot d with | .error e | .ok none |
  .ok (some p)` (generalized match) or `rcases ... with _ | opt` bullets.
- Do-blocks on Except: invert via `rcases hX : e with _ | x` plus the
  defeq-restatement trick (`have hstep : (match .ok s with ...) = X :=
  hc`). compileModel restructured into named helpers (assemble) so the
  inversion became tractable.
- Ident naming: after `obtain <n> := c.name`, hname : c.name.name = "x"
  IS defeq to `n = "x"`; use `ident_eq_of_name hname`.
- Correctness: hpending is quantified over problems, so `rw at hpending`
  fails; apply it FIRST (have h := hpending problem hc ...) then rw.
- Unreduced match goals: `trivial`/`rfl` fail; use the
  `have hm : (match [concrete, concrete] with ...) = False := rfl;
  rw [hm]` transport.
